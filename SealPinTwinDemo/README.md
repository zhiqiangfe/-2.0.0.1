# 锂电池密封钉焊接数字孪生

这是一个独立的 WPF + HelixToolkit 教学项目，不会替换或修改原来的食品包装线界面。场景聚焦一台密封钉焊接设备内部，不再表现整条流水线。

## 运行

双击 `run-seal-pin-twin.bat`，或在 Visual Studio 中将 `SealPinTwinDemo` 设置为启动项目。

也可以在终端执行：

```powershell
dotnet run --project SealPinTwinDemo.csproj
```

## 演示流程

1. 电芯由左侧升降门进机并进入伺服移载滑台
2. 滑台送至中央工位，夹具对中并完成测高
3. 清洗头扫描注液孔并模拟除尘
4. 真空吸嘴携带密封钉下降压装
5. 焊接头执行三点预焊和一周环形满焊
6. 同轴视觉往复扫描焊缝
7. 夹具松开，滑台将电芯从右侧送出设备

界面支持暂停、继续、故障注入、报警复位、工序定位，以及全景、俯视和正视相机。

详细版三维结构还包括双电芯托盘、四导柱顶升机构、H 形翻转压钉组件、XYZ
龙门模组、丝杆和拖链、CCD 环形光源、振动盘与直振轨道、焊烟除尘罩、
2D/3D 焊后检测头、对射传感器和气动阀岛。点击“焊接特写”可以近距离观察
预焊压紧、压块翻转避让以及双电芯环形满焊。

当前电芯已替换为海辰储能 `∞Cell 1175Ah / MC1175P025A` 参数化教学模型。
真实外形参数为 `580.22 × 75.22 × 216.31 mm`，标称 `3.2 V / 1175 Ah /
3760 Wh`，模型按照统一场景比例生成。顶盖、极柱、气道、防爆阀及密封钉为
依据官方外观资料制作的近似结构，并非海辰官方 CAD。

量产型设备外形已围绕该大储能电芯重新匹配：机架和底座扩大为长行程封闭
设备，中央龙门、进出料升降门和伺服轴均增加检修及安全空间；同时补充激光
器柜、水冷机、焊烟净化主机、后侧电控柜、气源处理、安全光栅、顶部桥架和
悬臂操作屏。全景用于观察整机布局，“焊接特写”用于观察中央密封钉动作。

## 说明

三维设备是根据公开工艺资料制作的原创教学级简化模型，并非厂商 CAD 文件，也不代表真实设备尺寸。
实时数据目前由本地模拟器产生，后续可以替换为 OPC UA、Modbus TCP 或 MQTT 数据源。
